Ü unikernel hello world

Ü is a compiled statically-typed general purpose programming language
with C-like syntax. Ü supports object-oriented paradigm, allows to write
generic code, has some functional programming elements and many other
useful features. Ü is created with error prevention in mind, has
safe/unsafe code separation and thus is memory-safe and thread-safe.


```
    bin/u.._build_system build_single hello_world.u
    ops run hello_world
```
